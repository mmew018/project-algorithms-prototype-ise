## Script สำหรับนำเสนอ 4–5 นาที

1. **ปัญหา:** ผู้ซื้อรู้การใช้งานและงบ แต่อาจไม่รู้ชื่อรุ่นหรือศัพท์สเปก
2. **Query 1:** แสดงการแยกเงื่อนไข การจัดอันดับ และเหตุผลของอันดับแรก
3. **Query 2:** แสดงคำค้นไทย/อังกฤษ สเปก GPU งบ และ Compare สองรุ่น
4. **Query 3:** แสดงการรองรับค่าตัวเลขและการ Sort/Filter
5. **Query 6:** แสดงว่าระบบถามเมื่อข้อมูลกำกวมแทนการเดาประเภทสินค้า
6. **Query 8:** แสดงขอบเขตและความโปร่งใสของ Prototype
7. **Benchmark:** สรุป 6 curated scenarios, K = 3 และย้ำว่า Ground Truth กำหนดโดยผู้จัดทำ
8. **Roadmap:** Fuzzy Matching, Semantic Retrieval, Validated AI Intent Parsing และข้อมูลจริง

ประโยคหลัก:

> Prototype นี้ไม่ได้อ้างว่าเข้าใจภาษาทุกรูปแบบ แต่พิสูจน์ Pipeline ตั้งแต่การแยกความต้องการ คัดเลือก จัดอันดับ อธิบายเหตุผล และจัดการคำค้นที่ไม่ชัดเจนได้อย่างตรวจสอบได้

## Checklist ก่อน Demo

- [ ] `node tests/regression.test.js` ผ่าน
- [ ] Query 1–8 ให้สถานะและผลลัพธ์ตามตาราง
- [ ] Compare ได้สูงสุด 3 รุ่นและไม่ข้ามกลุ่มสินค้า
- [ ] Unknown query ไม่แสดง Best Match หรือ Match Score
- [ ] Benchmark แสดง 6 scenarios และ K = 3
- [ ] หน้า About และ Footer แสดงข้อจำกัดข้อมูล/ราคา
- [ ] Desktop และ Mobile ไม่มีเนื้อหาล้นแนวนอน
- [ ] ใช้ Browser, Zoom และ Viewport เดียวกับวันนำเสนอ
- [ ] เตรียม Screenshot หรือวิดีโอสำรองสำหรับเหตุขัดข้อง
